这 21 枚印章是哪来的、为什么能用
================================

来源
----
game-icons.net（GitHub: game-icons/icons）。
全是单色剪影，原文件是 512×512 的 SVG。

授权
----
**CC BY 3.0** —— 可以用、可以改、可以随包分发，**但要署名**。
署名就在这儿，作者名单见同目录的 game-icons-CC-BY-3.0.txt：
主要是 Lorc 和 Delapouite 两位。

⚠️ **「要署名」和「不许分发」是两种完全不同的限制。**
いらすとや 那家是**禁止再分发**（原文拿 LINE 表情包举例），
所以只能她自己在手机上导（见 MyStickers）；
这一家只要求署名，打包进 App 是允许的。
我上一轮把两者混成一句「有限制」说过去了，那样说是不对的。

怎么做出来的
------------
SVG → PNG 走 `scripts/svg2png.py`。

⚠️ **那个光栅器是自己写的，纯 Python + Pillow，不要 cairo。**
当初 Hero Patterns 那批 SVG 没能进 App，理由写的是
「iOS 没有 SVG 光栅器，而 cairo 在她机器上装不上」——
这次扒 game-icons 又撞上同一堵墙（cairosvg / svglib / reportlab
装是装上了，一 import 就找 libcairo-2.dll）。

但这堵墙其实不高：要画的东西**就是一条填充路径的剪影**，
没有渐变、没有描边、没有文字、没有滤镜。那不需要一个完整的 SVG 引擎，
只需要「解析 d= 里那串命令 → 贝塞尔和圆弧压成折线 → 填成多边形」。
Pillow 全做得到，一百多行换掉一整个 C 库依赖。

挖空（甜甜圈中间那个洞）用的是「每个子路径各画一张、然后异或」——
那正是 evenodd 的定义，剪影类图标的洞基本都这么绕。

⚠️ 用法上跟实物贴纸**正相反**：这批**跟着主题色染**。
真印章本来就是一个颜色的；而一只蝴蝶翅膀上有七八种颜色，
染一遍就成一坨单色了。所以两批分开放、分开缓存。

这堵墙拆了之后
--------------
Hero Patterns 那批（CC BY）现在也能进了，还有 SVG Silh（CC0）。
下次要加纹样，直接走 svg2png.py。
