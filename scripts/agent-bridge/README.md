# 新桥：手机里的 Claude Code（会用工具那种）

旁边那座旧桥（`scripts/claude-bridge`）是把 Claude Code 装成一个**供应商**，
一轮一轮地问，工具是拿文字约的——他偶尔不照格式写，那一轮就白调。

这座新桥走的是 Claude Code 自己的流式协议（`--output-format stream-json`，
也就是 Agent SDK 底下那一套）：**工具是他真的在调，文件是他真的在改**，
每读一个文件、每跑一条命令，手机上都看得见。

两座桥可以同时开（旧的 8787、新的 8788），只开新的也行——
聊天页那个 **Code** 渠道只连新的。

---

## 用之前

电脑上单独跑一次，确认 claude 是登着的：

```
claude -p "说一个字：好"
```

打出「Not logged in」的话先 `claude` 登录一次（**要挂着平时用的梯子**，
终端不一定读系统代理，旧桥那份 README 里写了怎么让终端走代理）。

## 每次要用：起桥

双击 **启动新桥.bat**，或者：

```
set BRIDGE_TOKEN=自己编一串
node "D:\OneDrive\桌面\qi-nativev65\scripts\agent-bridge\bridge.js"
```

窗口里会打出：

```
接口地址  http://192.168.124.2:8788
```

## 手机上

聊天页左边栏 → **Code** → 右上角「接法」里填那个地址和密钥（跟电脑上那串一样）。

## 也能当「供应商」用：聊天页、工作页直接选它

设置 → 供应商 → 新增：

| 填什么 | 填成 |
|---|---|
| 接口地址 | `http://192.168.x.x:8788/v1`（**192.168 开头**那个） |
| 密钥 | 跟 `bridge-token.txt` 里一样 |
| 模型 | 点「从服务器拉取」：`sonnet` / `opus` / `haiku` 是改文件那一档，带 `-all` 全放开，带 `-read` 只看 |

选了它之后：
- 他用的是 **Claude Code 自己的工具**，每用一次回复里冒一行「› Edit 某某文件」
- App 那边的工具（记忆、日记、小屋……）**用不了**——Claude Code 不认那套
- **同一段对话接着同一个会话**：第二轮开始只把她新说的那句递过去（`--resume`）
- 工作区上面多一栏「电脑窗口」：挑接着电脑上哪个窗口说；不挑就是这段对话自己一个会话

### 会不会滚雪球、跟不跟电脑上一起压缩？

**跟电脑上的走，不在 App 这边滚。** 选了新桥的对话，App 自己那套滚雪球压缩直接跳过，
每轮也只递她新说的那一句；整段历史在电脑上那份会话记录里，
快满了由 Claude Code 自己压（跟电脑上一样的规则、一样的设置）。

## 可以接着已有的窗口聊

页面上「窗口」那一栏列的是**这台电脑上最近的会话**——
电脑上开过的那些窗口也在里面（`~/.claude/projects` 里一个 `.jsonl` 就是一个窗口）。

- 挑一个 → 之后每一轮都 `--resume` 那个会话，**他记得那个窗口里说过的话**
- 不挑 → 开一个新窗口；新窗口的 id 第一时间发回手机，接下来自动接着它说

⚠️ **电脑上那个窗口还开着的时候，别在手机上接着同一个会话。**
两头往同一份记录里写，记录会乱。要接就先把电脑上那个窗口关掉。

## 权限是一轮开始前就定好的

手机上没法弹「允许吗」，所以页面上那三档要先挑：

| 档 | 他能做什么 |
|---|---|
| 只看 | 读文件、搜索、查网页；不改东西（`--permission-mode plan`） |
| 改文件 | 默认。可以改文件（`acceptEdits`） |
| 全放开 | 命令也随便跑（`--dangerously-skip-permissions`） |

## ⚠️ 安全

这座桥等于把这台电脑的命令行摆在了局域网上。所以：

- **没设 `BRIDGE_TOKEN` 就什么端点都不开**，只回一句「没设密钥」
- 密钥文件 `bridge-token.txt` **不进仓库**（仓库是公开的）
- 只监听局域网；出门在外要用得自己搭隧道，这边不管

## 拧螺丝的地方

| 名字 | 默认 | 干嘛的 |
|---|---|---|
| `BRIDGE_PORT` | 8788 | 换端口 |
| `BRIDGE_TOKEN` | 空 | 密钥，**必填** |
| `BRIDGE_WORKSPACE` | 这个仓库 | 默认在哪个目录里干活 |
| `BRIDGE_CONCURRENCY` | 2 | 同时最多跑几轮 |
| `BRIDGE_TIMEOUT` | 1200000 | 一轮最多跑多久（毫秒） |
| `BRIDGE_CLAUDE` | 自动找 | claude 本体路径 |

## 端点

| 方法 | 路径 | 干嘛的 |
|---|---|---|
| GET | `/` | 通不通（这一个不要密钥） |
| GET | `/v1/sessions?limit=25` | 这台电脑上最近的窗口 |
| POST | `/v1/agent` | 跑一轮，ndjson 流回事件 |
| POST | `/v1/interrupt` | 叫停某个会话正在跑的那一轮 |

`/v1/agent` 收 `{text, session?, cwd?, mode?, model?}`，流回：

```
{"t":"session","id":"…","cwd":"…","model":"…"}
{"t":"text","delta":"他正在说的字"}
{"t":"think","delta":"（他在想什么，开了才有）"}
{"t":"tool","id":"…","name":"Edit","brief":"哪个文件"}
{"t":"tool_done","id":"…","ok":true,"brief":"头一行结果"}
{"t":"done","ms":12345,"cost":0.03}
{"t":"error","msg":"…"}
```

## 连不上的时候

1. 电脑浏览器进 `http://127.0.0.1:8788/` —— 打出「新桥是通的」说明服务没问题
2. 手机浏览器进 `http://192.168.x.x:8788/` —— 打不开就是 WiFi/防火墙：
   Windows 第一次会弹「允许 Node.js 通过防火墙」，**要点允许，还要勾上专用网络**
3. 两台在同一个 WiFi 上（手机别挂流量）
4. 黑窗口里每一轮都有日志（接着哪个窗口、哪一档权限、跑了几秒）
