# pixel-art：让 Claude Code 画精细像素图

## 为什么不一格一格摆

一格一格摆像素（字符画、手写坐标）画不出弧线、画不出透视，而且**一批东西光照各画各的**，
摆进同一间屋子一眼就散。这套做法是：

1. **搭形体**：用基本体拼一个小立体模型（车床体、圆柱、球、椭球、圆环、胶囊、圆角盒）
2. **统一打光**：光固定从屏幕左上来，包裹式兰伯特 + AO + 投影 + 高光
3. **量化**：每种材质只有 5–7 档颜色，按亮度落档，交界处 2×2 有序抖动
4. **描边**：外轮廓深红棕线 + 里面一圈浓色；不同部件前后相叠处，靠后那侧压暗
5. **折痕**：同一件东西法线急转的地方（杯口、盘沿），朝光侧提亮一档、背光侧压暗一档
6. **清杂点**：同材质里孤零零一个跟四邻都不一样的点抹掉

出来的每一格仍是一个像素，但形体和光是算的：**成套画时颗粒度、光向、色调天然一致**。

## 用法

```python
import sys; sys.path.insert(0, ".claude/skills/pixel-art")
from pixelkit import *

s = Scene(size=150, view="iso", units=4.6, target=(0, 0.7, 0))
cup = Material("cup", "#F7E6C8", steps=7, gloss=0.7)
s.add(lathe([(0, 0.12), (0.72, 0.12), (1.15, 0.55), (1.34, 1.62), (1.25, 1.62), (1.06, 0.55), (0, 0.28)]), cup, "cup")
s.add(torus(0.36, 0.11, axis="z").rot("y", 45).at(1.03, 1.02, -1.03), cup, "cup")
img = s.render()
save(img, "cup.png")
preview([img], "cup_look.png", zoom=4)
```

完整例子：`examples/tabletop.py`（咖啡、蛋糕、茶壶、蜡烛 + 跟资产包原图的对照图）。

## 规则（都是试出来的，别改回去）

### 画面
- **视角**：`view="iso"` 是 2:1 斜俯视，跟资产包 `top_front_left` 同角度；`"front"` 是正面略俯视（平面屋、商城卡片）
- **世界方向**（iso 下）：屏幕右 = `(+x, -z)`，朝着观察者 = `(+x, +z)`。把手摆 `rot("y", 45)` 再放到 `(+d/√2, y, -d/√2)`
- **颗粒度**靠 `size / units`：同一批东西 `units` 按实物大小给，别每件各调到填满画布——不然杯子和茶壶一样大
- 原图宽 130–150 像素时细节跟资产包 192 像素那批缩到同高是一个量级

### 颜色（`ramp`）
默认 `STYLE = "vivid"`（名字叫 vivid，实际是**干净但不艳**的那档）；`"warm"` 是第一版，留着对照。

她看过的三版，结论：
- 第一版（warm）：暗部一律往红棕走、底色全是奶黄 → 「朴素、有年代感」
- 抬饱和那版（中间调 ×1.18）→ 「太鲜艳太饱和」
- 现在：中间调只 ×1.04，暗部往**玫瑰紫**偏、饱和度加得克制；底色给干净的白瓷 / 淡蓝 / 淡紫，
  点缀色（杯口线、花、条纹）用**柔的**珊瑚、薄荷、雾蓝，不用正红正蓝

规则：
- **暗部靠饱和度往上走、明度只掉一点**（明度掉多了是脏棕）
- 近白的材质（白瓷、奶油）暗面往淡紫灰、只加一点饱和，否则整片发粉
- 深色材质（咖啡、木头）把 `shine` 调低（0.1–0.2），否则顶面被光打成橘/奶泡色
- 描边是最暗档再压一截的深梅红，**不用黑**
- 自发光（火苗、屏幕）取原色那档，不取最亮档

### 热气、烟
`steam(img, x, y, ...)`：几根一行一像素的正弦细线，底宽顶窄、越往上越淡、顶端断成点，
白芯外贴一格淡暖色（浅底上才看得见）。位置用 `Scene.project()` 从杯口算，画布要留出上方高度。

### 曲线图案（拉花、花纹）要一条线画完
拼接出来的形状（两个圆 + 一个楔形）肩膀处会有角，她一眼看出「衔接突兀」。
能用一条闭合参数曲线的就用曲线（心形 `x=16sin³t, y=13cos t−5cos2t−2cos3t−cos4t`），
要变形就**渐进地**变（按位置的幂次加权），不要一段一段拼。多边形内判断用射线法（见例子 `inside`）。
画在液面、桌面这种水平面上的图案，竖向比例要给大一点——斜俯视下水平面竖向被压扁一半。

她给的参考（小红书像素食物）里值得学的：
- 大白心：两边是一整条外凸的弧，尖稍微拖长
- 像素食物普遍是 1 像素暖深棕描边、3–4 档平涂、几颗高光像素点；
  面包、蛋糕胚、冰拿铁分层靠**抖动噪点**做质感和过渡，不是整块平色

### 从拼豆图纸学到的（她给的可颂 / 果盘图纸，一格一色号 = 一像素）
跟算出来的「干净渲染」比，手画像素图多了这几样，**面包、糕点、水果这类要质感的东西都开上**：
- **颜色多、跨度大**：一件东西 10–18 色，从近白一路到近黑。材质用 `colors=` 直接给一整串
- **颗粒** `Material(grain=0.4–0.7)`：同一块面上相邻两档一颗一颗掺着（酥皮、蛋糕胚、果肉）。
  清杂点在颗粒之前做，不会把颗粒抹掉
- **高光亮条** `Material(streak=0.3–0.6)`：最亮那一圈里随机点亮、往白里提
- **节间深色带** `Scene(seam=2, seam_depth=3, seam_all=True)`：节与节之间两三像素宽、压暗三档，一直接到外轮廓
- **轮廓一种颜色** `Scene(inner_ring=False, contour=True)`：去掉描边里那圈浓色（会磨平台阶），
  两件东西相接时靠前那件描自己的深色一圈（可颂压在盘子上是深棕边，不是盘子被压暗的浅蓝）
- 这些参数可以在生成函数里直接改 `s.seam = 2` 这样设

### 同类的几个要放在同一条前后线上
蛋糕上三根蜡烛前后错开摆，斜俯视下靠后那根显得又长又细、火苗被挡——她一眼看出来。
几个同样的小件沿屏幕左右（iso 下世界 `(+x, -z)`）排开，看着才一样。

### 一个模型出好几个视角
成套换进 App 时每件要三张：等距（贴左墙）、等距（贴右墙，yaw −45）、正面（yaw 0，平面屋和商城）。
**所有跟视角有关的摆放都用 `R, T = s.axes()`**（R 屏幕右、T 朝着观察者，都在水平面上）：
- 把手：`along(torus(..., axis="z"), R)` 放在 `R * d`
- 镜头、喇叭口朝前：`face(shape, T)`
- 正面的标签、花纹：贴花里用 `t = p·T`（朝前多少）、`v = p·R`（往右多少）
- 水平面上的图案（拉花）：`u = p·R`、`w = −p·T`
写死 `(+x, −z)` 的话，换到右墙视角把手就跑到背后去了。生产脚本见 `scripts/px_tabletop.py`。

### 形体
- 三角形的东西（饭团、三明治）→ `tri_prism`，尖朝本地 +y、沿本地 z 拉出厚度
- 糖粒、芝麻、面包屑、苔藓、珍珠 → 贴花里用 `speckle(p, scale, density, seed)`；按格取随机数用 `hashv`
- 杯、瓶、壶、蜡烛、蛋糕层 → `lathe`，轮廓 `(r, y)` 首尾落在轴上，可以往回折出杯壁和杯内
- 弯管（壶嘴）→ 几段 `capsule` 首尾相接渐细，**别用一串球**（会画成珠子）
- 液体、内容物放进容器时半径要小于那个高度上的内壁半径，否则会穿出杯壁
- 同一件东西的几块给同一个 `group`，中间不描内线

### 贴花（花纹、拉花、标签、条纹）
- `s.decal(fn, onto=group)`，`fn(p)` 收到的是**那块基本体的局部坐标**（`.at()` 之前的），返回 `(mask, Material)`
- 贴花照样吃光照；后加的盖前加的
- 朝着观察者那一面：`u = (x + z) / √2 > 某值`

### 玻璃
`alpha < 1` 的材质走第二层叠加，目前只是近似（整体叠色 + 亮档反光 + 描边），复杂的玻璃罐效果还不够好。
